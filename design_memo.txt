Design Memo: Hospital Data Structures

A binary tree is a good choice for organizing the hospital's doctor reporting structure because it shows how doctors are connected to other doctors. Each doctor can have a left and right report, making the structure easy to follow. The tree also makes it possible to search for a doctor and see how the reporting structure is organized. If the hospital changes its management structure, doctors can be added to the tree in the correct positions.

Preorder, inorder, and postorder traversals are useful because they visit the nodes in different orders. Preorder visits the parent before the children, which can help create a report that starts with the highest-level doctor. Inorder visits the left child, parent, and right child, which can help display information in a consistent order. Postorder visits the children before the parent, which can be useful when processing lower-level departments before higher-level ones. These traversal methods give software engineers different ways to organize and process data.

A min-heap is useful for emergency intake because it keeps the patient with the highest priority at the front of the queue. In this project, a lower urgency number means the patient needs attention sooner. When a new patient is added or the highest-priority patient is removed, the heap rearranges itself to maintain the correct order. This makes adding and removing patients efficient, even when many patients are waiting. Overall, trees and heaps solve different problems and help hospitals organize information and prioritize patient care.
